## 下载

到 [GitHub Releases](https://github.com/AstralNext/AML/releases/latest) 获取最新正式版。

- **Windows 安装包**（推荐）：`aml-*-windows-x64-setup.exe`
- **Windows 便携包**：`aml-windows-x64-*.zip`
- Linux / macOS 也有对应压缩包

安装包会创建开始菜单与可选桌面快捷方式，并注册 `aml://` 协议（实例快捷方式需要它）。
